做幣本位合約最怕的事：賺了一大段才發現邊際效率早就掉到地板，或是倉位太分散根本不知道整體曝險多少。這個工具就是拿來解決這件事的。

這個工具在幹嘛

幣本位逆馬丁金字塔追蹤器是一個純前端的互動工具，用來管理和監控幣本位（Coin-Margined）做多倉位。核心邏輯是逆馬丁格爾（Reverse Martingale）策略 — 順勢加倉，而不是逆勢攤平。

👉 直接打開工具

功能一覽

1. 即時損益計算

輸入 BTC 現價後，每個倉位會自動算出：

  • BTC 損益 — 幣本位的實際盈虧（以 BTC 計）
  • USD 損益 — 換算成美元的盈虧
  • ROI% — 分別以 BTC 和 USD 計算的投資報酬率

2. 清算價與清算距離

每個倉位都會顯示：

  • 清算價格 — 根據入場價、槓桿、維持保證金率（預設 0.5%）計算
  • 清算距離 — 現價離清算價還有多少百分比，用顏色標示安全程度：
    • 🟢 < -35%：安全
    • 🟡 -25% ~ -35%：注意
    • 🔴 > -25%：危險

3. 邊際效率監控

這是這個工具最核心的功能。幣本位合約有一個特性：漲越多，每多漲 1% 帶來的 BTC 收益越少。這就是邊際效率遞減。

公式：邊際效率 = 1 / (1 + 漲幅)²

工具會自動提醒你：

  • 效率 > 50%：繼續持有
  • 效率 30% ~ 50%：可考慮部分止盈
  • 效率 < 30%：強烈建議止盈重開

4. 資金配置總覽

一眼看清楚：

  • 總保證金佔比
  • 可用剩餘資金
  • 總曝險和有效槓桿
  • 帳戶淨值（含未實現損益）
  • 視覺化的資金配置條

逆馬丁格爾的操作邏輯

傳統馬丁格爾是「虧了加倍押」，遲早爆倉。逆馬丁格爾反過來：

  1. 初始倉位用小保證金、低槓桿
  2. 價格往有利方向走，用獲利的一部分開新倉
  3. 每次加倉都是獨立倉位，不是加碼同一倉
  4. 邊際效率低於閾值就止盈，鎖定利潤後重新開始

關鍵心態：止盈不是認輸，是重置效率曲線。止盈後把實現的 BTC 利潤加回「總資金」，再用新的入場價開倉，效率重新回到 100%。

使用方式

  1. 輸入 BTC 現價 和你的 總資金（帳戶裡的 BTC 總數）
  2. 用下方表單 新增倉位：填入入場價、保證金、槓桿
  3. 觀察各倉位的損益、清算距離、邊際效率
  4. 收到效率衰減提醒時，考慮止盈
  5. 止盈後更新「總資金」為帳戶實際 BTC 數量

技術細節

  • 純前端 React 應用，不傳送任何資料到伺服器
  • 所有計算在瀏覽器本地完成
  • 資料不會儲存，重新整理就會清空（刻意設計，避免過期資料誤導判斷）
